BSM 無法直接從 Put 價格倒推股價，改用二分搜尋法逐步逼近：
在 [0.01, S] 區間反覆對分 → 計算中點的 BSM Put → 誤差 < $0.00005 即停止，通常 20–50 步收斂。
diff > 0（Put 太高）→ lo = mid，往高股價找；diff < 0（Put 太低）→ hi = mid，往低股價找。
