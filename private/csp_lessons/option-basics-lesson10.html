WHAT IS OPTIONS FLOW
期權資金流向
什麼是 Options Flow？
①Options Flow 是期權市場上每一筆真實成交紀錄的彙整，記錄了 Strike、到期日、Call/Put 方向、成交量、Premium（權利金總額）等完整資訊。
②Premium 大小才是判斷「有無大資金押注」的關鍵。一筆 $500,000 以上的期權交易，很可能來自機構或對沖基金，不是散戶行為。
③成交方向（Side）最重要 ：ask = 主動買入（看多/看空意圖強）；bid = 主動賣出（通常是造市商賣期權收保費）；mid = 中間價成交（方向不明，不計入情緒指標）。
④從 Barchart.com 可免費下載個股的 Options Flow CSV，欄位涵蓋 Symbol、Type、Strike、Expires、DTE、Size、Side、Premium、Delta 等。

SIGNAL READING
信號解讀
如何判讀市場情緒？
🟢 看多信號（Bullish）
• 大筆 ask-side Call 成交
• Call Premium 顯著 > Put Premium
• 高 Delta Call（≥ 0.70）大量買入
• 長 DTE Call（>180天）機構押注
• 價外 Strike 大量成交
🔴 看空信號（Bearish）
• 大筆 ask-side Put 成交
• Put Premium 顯著 > Call Premium
• 低行使價 Put 大量買入
• 短 DTE Put（<30天）短線對沖
• 價外 Put 異常大量成交
⚠️ 注意：Options Flow 只是情緒指標，不代表方向一定正確。機構也可能用期權做對沖（與持股方向相反）。建議搭配技術面與基本面一起判斷，不可單一指標決策。
