3
IV PERCENTILE RANK
重要指標解析
📊 IV Percentile Rank（IV PR）
決定開倉時機的核心指標
📌 IV PR 是什麼？
過去一年（約 252 個交易日）中，有多少百分比的交易日 IV 低於今天的 IV。

IV PR = 60% → 過去一年有 60% 的天數 IV 比今天低
→ 目前 IV 處於過去一年的前 40% 高位

⚠️ 計算的是「天數比例」，對極端值（黑天鵝）的敏感度低於 IV Rank。
💡 為什麼重要？
IV PR 告訴你現在的期權 Premium 是「貴」還是「便宜」：

IV PR > 50% → Premium 偏高 → 賣方有利（CSP / CC）
IV PR < 30% → Premium 偏低 → 買方有利（Long Call/Put）

策略規則：高 IV PR 賣期權，低 IV PR 買期權。

IV Rank vs IV Percentile — 常混淆的兩個名詞
🏆 IV Rank
公式：(今日IV − 52週最低) ÷ (52週最高 − 52週最低)
比較：只看最高和最低兩個極值
缺點：一次黑天鵝大漲 IV，之後長期 Rank 都會偏低
Barchart 顯示的是此版本
📊 IV Percentile (IV PR)
公式：過去一年中 IV 低於今日的天數 ÷ 總交易日數
比較：統計每一天的 IV，更能反映「一般水準」
優點：對黑天鵝更穩健，分佈更均勻
TastyTrade / Market Chameleon 常用此版本
